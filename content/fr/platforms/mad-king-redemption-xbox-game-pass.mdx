Quelques règles de base qui évitent de vrais maux de tête :

- Les codes sont souvent verrouillés par région. Un code acheté pour un autre pays peut échouer sur votre compte.

- Après activation, vérifiez ce que vous avez reçu. La page des abonnements indique la durée d'abonnement ; l'historique des commandes indique la possession du jeu.
